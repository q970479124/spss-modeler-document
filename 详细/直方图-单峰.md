## 一、 分布形态 ##

### 1. 偏态 ####
从图可得，数据呈轻微的左偏态，存在尖峰现象  
判断依据: 长尾在左侧为左偏态，整体近似单峰形态分布，并且中间有明显的集中分布且数据较多  

结合描述性信息分析  
数据分布范围在0.2337 ~ 1.1204 范围之间，没有明显的异常数据出现（没有较远的离散数据，初步判断，后续会结合箱线图等）  
峰度为0.33332 偏度为-0.8075 证实了数据呈一个左偏态的分布（偏态为负数说明左偏，且接近-1，说明有较明显的偏态，但是偏态较为轻微，且峰度小于0.5尖峰不算明显）  
平均值更接近较大值，说明数据分布中数值大的数据更多，且众数要比平均值大也证明了这一点，平均值接近中位数，说明数据中基本没有极端值的存在  
数据在分布范围内有明显的上升和下降趋势，因此判断数据有一定的波动，从标准差来看，数据波动不算严重，应该在合理范围内（标准差小于最小值，且是最大值的6-7倍左右，且远小于波动范围）
IQR不做计算，箱线图会体现  

考虑处理手段：
1. 可暂不处理
2. 考虑计算box-cox做正态分布转换
3. 由于数据有明显的分层，高柱和矮柱，因此可以考虑分组建模，或者做分箱分类（大致两类其实是二值化）

python代码
```
from scipy.stats import boxcox
transformed_data, best_lambda = boxcox(data)
```

- λ ≈ 0 → 等于 log 变换
- λ ≈ 0.5 → 根号
- λ ≈ 1 → 不用变
- λ ≈ 2 → 平方
- λ ≈ 3 → 立方
