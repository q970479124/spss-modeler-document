# 数据质量分析 #
数据质量分析的核心在于通过审计数据的统计分布特征，识别并量化缺失值、异常范围及逻辑矛盾，从而确保输入模型的信息具备业务上的真实性与统计上的可用性。

## 一、完整性审计 ##
判断数据是否有分析的价值、数据格式是否有异常情况（如果这时候分析结果不合规则数据没有继续分析的必要了）。  

<br>

### 1. 缺失值（缺失率） ###
用来衡量数据质量的主要指标  
作用：体现数据整体缺失情况，同时也说明了要修补的工作量有多少，如果缺失严重则说明数据不具备分析和预测的条件。  
行业基准(通用)：`需要考虑特征的重要性，重要特征需要收紧基准` 
`< 5%`,几乎不影响大局，可以直接忽略或简单填补。  
`5% - 20%`,需要通过算法补全（插值）或查明原因，分析价值尚存。  
`20% - 50%`,数据已经严重“失真”，除非该字段不重要，否则分析结果不可靠。  
`> 50%`,除非有极强的业务逻辑能解释，否则这个维度基本失去分析价值。

注意点：
- 预测值（填充值）本身就不是完全准确的值，会放大最终的预测误差。
- 工业上一般严格的控制标准在重要特征 1%以内一般特征 5%以内

<br>

### 2. 有效值 ###
用于检查数据中是否存在格式错误、非法字符、类型冲突。  
作用：防止由于数据格式的不统一而导致建模时的程序错误或权重偏移。  
注意点：部分情况可以将其当作缺失值处理或进行格式标准化处理。  

<br>

### 3. 唯一值 ###
用于反映数据中不重复的数据有多少。（相当于当前列中去重后有多少不同值）  
作用：主要数据的多样性、颗粒度、及逻辑性问题。  
注意点：
- 连续型特征(例如小数型数据)一般不考虑唯一性，因此表格中显示值为0，正常情况唯一值最小也是1。  
- 分类型特征唯一值越大说明数据越多样，同时也说明数据越复杂。越复杂的数据规律性越差，越难分析，因此当数据特征中的值基本不重复时候，这类数据就认定为没有分析的价值。  
- 当唯一值为1的场合说明数据没有波动，因此此类数据不需要分析可以直接舍弃(数据是常数不是没有规律，而是不体现规律)。  
- id作为一种特殊且不重复的数据，唯一值要么等于数据总条数，要么显示为0，如果出现其他情况则考虑数据存在重复记录或逻辑异常数据。
- 可能作为一种分组操作的规划手段。  
<br>

## 二、边界与准确性审计 ##
判断数据是否在业务合理范围，是否存在不合理数据(极端或记录错误)

### 1. 最大值与最小值 ###
直观的反映数据分布范围。  
作用：体现了数据的天花板和地板，搭配业务中设定的数据范围，直观体现数据是否超过业务边界，反映出极端/异常数据是否存在。  
案例：正常人类年龄大致在1～120之间，如果数据中出现负数或超过120的数据，则认为超出合理边界，数据存在极端/异常。  
处理手段：一般采用截断(盖帽)、分箱、删除(次方法可能影响数据完整性，慎用)。  

<br>

### 2. 范围 ###
直观反映数据的深度(最大波动范围)，与最大值最小值共同表示不同角度的数据范围。  
作用：反映数据跨度、数据离散程度、最大波动范围、以及低级错误。  
注意点：
- 比如相同水平年限的员工工资范围在5000，说明数据跨度大。  
- 结合数据分组判断数据的敏感程度，例如一个班级分数范围在50，另一个班级的分数范围在10，说明第一个班级分数更松散。  
- 比如人类正常寿命的最大范围在120，而数据范围在200，可以判断出数据存在明显的异常情况。  
- 当去除掉极端值后能够初步反映数据的波动情况(极端值的存在可能造成一个大波动的假象)。

<br>

### 3. 界外值 ###
反映数据的异常情况，界外值 = 异常值 = 离群值。  
行业标准：为1.5倍的IQR（IQR = Q3 - Q1）  
  - 下限 = Q1 - 1.5 × IQR  
  - 上限 = Q3 + 1.5 × IQR  

<br>

## 三、稳定性审计 ##
反映数据的集中程度、松散程度、分布形态的偏向。  

### 1. 集中趋势指标 ###
主要反映数据的中心位置，指标有以下内容：  
- 均值
- 中位数
- 众数

<br>

#### a. 均值 ####
反映数据列中整体数据的平均值。  
作用： 看数据的整体水平。  
注意点：容易被异常值或极端值影响，如果平均值不位于数据的中心，则说明数据不符合正态分布。  

<br>

#### b. 中位数 ####
反映数据从小到大排序后的最中间的那个数。 
作用：看数据的整体水平。  
注意点：不易受异常值和极端值的影响，但是不能反映出数据的平均状态。  

<br>

#### c. 众数  ####
反映数据中出现次数最多的那个数，反映数据的扎堆情况。  
作用：提取数据中最常见的数。

<br>

### 2. 离散趋势指标 ###
- 极差
- 方差
- 标准差

<br>

#### a. 极差 ####
反映数据的波动范围。  

实际是最大值和最小值间的差值  
极差小: 说明数据分布集中  
极差大: 说明数据比较分散波动大  

极差跨度大说明有可能会出现异常值


<br>

#### b. 方差 ####
反映所有数据相对于平均值的平均偏离程度

- 方差大: 数据比较松散，且数据波动比较大，会被极端值影响  
- 方差小: 数据比较集中，基本都接近平均值，波动较小  

规则: 方差极小接近0 则说明数据没有波动，分析意义不大（排除单位本来就很小）。方差极大，说明存在异常值/极端值的影响  

由于方差是差值的平方因此会被极端值放大，并且不易和原始值对比  

<br>

#### c. 标准差 ####
与方差相同，但是标准差是方差的开根号，还原了单位，更容易被观测  

与方差原理相同，用途相同，仅仅是单位尺度不同，更易被看懂和使用。  
方差偏向于计算，标准差偏向于观测和报告  

标准差 + 均值 就是描述正态分布的关键指标（加上偏态和峰度能够反映出一个非正态分布的图解）  

<br>

#### d. 残差 ####
反映的是模型预测结果的好坏，主要是实际值与预测值的差值的体现，直接反映出预测错误了多少错的那部分就是残差

- 残差越小，模型越准确，精度越高  
- 残差的正负反映模型预测结果是整体偏高还是偏低  
- 高精度的模型残差一定是符合正态分布的  
- 预测值是模型可以解释的部分，是能够抓住规律的部分，残差是模型解释不了的部分也就是模型没有学习到这部分规律  

<br>
  
### 3. 分布形态指标 ###
<br>

#### a. 偏度 ####
反映数据是否对称, 仅能证明符合正态分布规则，但是并不能证明一定是正态分布
 
- 偏度 ≈ 0 ： 说明数据左右对称，中位数 ≈ 平均数，数据符合正态分布  
- 偏度 < 0 :  说明数据向左偏，尾巴在左边，平均数 < 中位数，数据呈左偏态分布  
- 偏度 > 0 :  说明数据向右偏，尾巴在右侧，平均值 > 中位数，数据呈右偏态分布  

| 区间	                      | 状态	   |处理建议                      |
| -------------------         | ------   | --------------------------- |
| -0.5 ~ +0.5                 | 对称      | 无需处理                    |
| -1.0 ~ -0.5 或 +0.5 ~ +1.0  | 轻微偏态  | 建议 log / 根号 / Box-Cox    |
| <-1.0 或 > +1.0             | 偏态      | 必须变换 + 缩尾              |
| <-2.0 或 > +2.0             | 严重偏态	 | 剔除或分箱                   |

- 右偏：存在少数极大值
- 左偏：存在少数极小值
<br>

#### b. 峰度 ####
反映数据形成的分布图中是否存在尖峰厚尾现象

- 常峰度: 峰度 = 3, 标准正态分布曲线，不尖不厚  
- 尖峰: 峰度 > 3, 中间尖，两边尾巴厚，反映数据集中（数据多分布在中间），但同时异常值会更多
- 扁峰: 峰度 < 3, 顶部更平，尾巴较薄，反映数据比较分散，极端值较少

注意： 程序中显示的峰度一般为超额峰度，需要在原始峰度的基础上减去3，因此标准常峰度会等于0  


| 区间	                      | 状态	       |处理建议                      |
| -------------------         | ------       | --------------------------- |
| -0.5 ~ +0.5                 | 近似正态      | 无需处理                    |
| > 0.5 && < 1.0              | 略尖         | 建议 log / 根号 / Box-Cox    |
| > 1.0 && < 3.0              | 过尖         | 必须变换 + 缩尾              |
| > 3.0                       | 极端厚尾尖峰	 | 剔除或分箱                   |
| < -0.5 && > -1.0            | 略平         | 建议 log / 根号 / Box-Cox    |
| < -1.0 && > -3.0            | 过平         | 必须变换 + 缩尾              |
| < -3.0                      | 极端薄尾平峰	 | 剔除或分箱                   |

<br>

- 偏度大: 平均数不可靠，用中位数
- 峰度高: 极端值多，用 IQR 识别异常值
- 偏度≈0、峰度≈+-0.5: 接近正态分布

<br>

## 四、其他指标 ##

### 1. 分位数 ###
反映数据的分布形态，通过数据判断数据的异常区间和正确的分布范围

- 0%（最小值）
- 1%、5%（左尾）
- 25%（Q1）
- 50%（中位数）
- 75%（Q3）
- 95%、99%（右尾）
- 100%（最大值）

<br>

#### a. 四分位数 ####
**第 25 个百分位数** ，**第 75 个百分位数**  把一组数据从小到大排序，并按照25%和75%切分  
反映数据的集中与分散，结合最大值最小值中位数可以看出数据的集中范围。

什么是中位数: 代表整体中间水平（50%），不受极端值影响。（中位数位置计算公式： 数据总数 * 0.5)  
如果数据总数是偶数则中位数是中位数位置前后对应值的平均值，如果是奇数个则为中位数位置向上取整后对应的值。    
什么是25分位数： 代表数据整体的25%分布数  
可以抽象成数据前50%的中位数去理解。  
什么是75分位数： 代表数据整体的75%分布数，参考25分位数去理解。  

#### b. IQR ####
IQR 是四分位距（75%-25%）主要反映围绕数据中间的50%的数据分散程度  

数据越集中IQR越小，越分散IQR越大。  
作用： IQR的主要作用是用来初步区分异常值范围的，不会被极端值影响。  
主要用在箱线图中。  
行业标准为：(系数1.5)   
- 下界：Q1−1.5×IQR  
- 上界：Q3+1.5×IQR
  
<br>

# 分类型数据探索注意点 #
基本上仅需要观测各个类别的占比来判断数据分布是否平衡，以及一些稀有类别的提取，为后续和合并、分箱、二值化提供参考依据。

常见的处理方式：  
独热编码 = 一个类别作为一列，然后做二分类0和1，要注意的是类别不能过多，否则会产生维度爆炸  
目标编码 = 用「这个类别对应的目标变量均值」来代替原来的类别名称  
频率编码 = 用「这个类别出现的次数/占比」来代替原来的类别名称  
标签编码 = 用数字 0 ，1 ，2 ,....标记原始分类
